## 🛠️ Requisitos

- [Dart SDK](https://dart.dev/get-dart) (3.x recomendado)
- Un editor como [Visual Studio Code](https://code.visualstudio.com/) con la extensión oficial de **Dart**

Para comprobar que Dart está instalado:

```bash
dart --version
```

## ▶️ Cómo ejecutar los ejercicios

1. Clona el repositorio:

   ```bash
   git clone https://github.com/XanKeeTee/ejerciciosDart.git
   cd ejerciciosDart
   ```

2. Entra en la carpeta de la relación que quieras probar:

   ```bash
   cd "RELACIÓN DE EJERCICIOS DE DART (I) EJERCICIOS INICIALES"
   ```

3. Ejecuta un ejercicio (sustituye `ejercicio1.dart` por el nombre del archivo):

   ```bash
   dart run ejercicio1.dart
   ```

También puedes abrir la carpeta en VS Code y ejecutar cada archivo con el botón **Run** o con `F5`.
